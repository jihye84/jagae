# 자개 붓

검은 옻칠 위에 나전칠기를 붓칠하듯 그려 보는 웹앱이에요.
빛이 움직이면 자개가 무지갯빛으로 일렁여요.

주소: https://jihye84.github.io/jagae/

## 도구

| 도구 | 하는 일 |
|---|---|
| 자개 붓 | 깨진 자개 조각(할패)을 붓질하듯 박아 넣어요. 톡 찍으면 조각으로 채운 원이 생겨요. |
| 통자개 | 한 덩어리 자개판을 넓혀 가요. 같은 자개끼리 닿으면 결이 이어져 한 덩어리가 되고, 다른 자개와 겹친 경계에는 옻 선이 생겨요. |
| 오리기 | 하늘(해, 영지·뭉게·흐름·말림·겹·바람구름), 산수(일월오봉도, 오봉, 폭포, 산, 바위, 물결, 그리고 끌어서 정한 네모 범위를 채우는 파도·비늘물결·굽이물결), 꽃·나무(소나무, 적송, 대나무, 연꽃, 매화, 불로초), 새·짐승(학, 사슴, 범나비·꽃나비·점나비·긴꼬리나비·호랑나비·앉은나비·쌍나비·나비원문, 거북, 봉황), 문양(격자창살, 아자문, 칠보문, 매듭문, 꽃살문, 꽃창살, 빗살창살, 팔각문, 번개문, 태극), 글자(둥근 수, 모난 수, 복, 쌍희), 띠(번개띠, 回자띠, 工자띠, 창살띠, 당초띠 — 끈 선을 따라 이어 붙음) 무늬를 골라 찍어요. 새·구름처럼 방향이 있는 무늬는 끄는 방향으로 좌우가 바뀌고 기울어요. 대나무·소나무·산처럼 서 있는 무늬는 위아래로 끌면(위→아래든 아래→위든) 아래쪽 끝이 밑동이 되어 그 방향으로 기울여 세워져요(35°까지). '손으로'를 고르면 테두리를 직접 그려 오려요. |
| 선각 | 자개 위에 가는 홈을 새겨 옻이 찬 것처럼 검은 선을 넣어요. |
| 끊음질 | 가늘게 자른 자개 실을 끊어 가며 줄지어 붙여요. |
| 부스러기 | 잘게 부순 자개를 흩뿌려요. 마우스를 올리면 뿌려질 범위가 점선 원으로 보여요. |

서로 다른 기법(자개 붓·통자개·끊음질·부스러기·오리기)이나 다른 자개끼리 겹치면, 나중에 붙인 조각 둘레에 옻 선이 저절로 생겨 오려 붙인 것처럼 보여요. 같은 자개의 통자개끼리는 한 덩어리로 이어져요.

자개는 전복·진주·야광패 세 가지, 굵기는 실·가늘게·보통·굵게·달만큼 다섯 단계예요.
되돌리기는 12번까지, 초기화는 두 번 눌러야 지워져요.

## 화면

- 시작 화면: 처음 열면 옻칠판 모양(화면 맞춤·정사각형·3:4·4:3·족자 1:2·16:9)을 고르고 「옻칠판 펼치기」를 눌러요. 고른 모양은 다음에도 기억해요. 누르면 주소창이 사라진 전체화면으로 옻칠판이 펼쳐져요.
- 전체화면: 뒤로 가기 등으로 전체화면에서 나오면 그대로 창 모드로 두어요. 도구 띠의 「전체화면」으로 다시 들어가요. 도구 띠의 「전체화면/창 모드」로 켜고 끌 수 있어요. 아이폰은 사파리에서 공유 → 「홈 화면에 추가」로 연 앱에서 주소창 없이 보여요.
- 옻칠판: 도구 띠를 피한 자리에 테두리가 있는 판으로 놓여요. 판의 가로세로 비율은 화면과 같아요. 판 바깥 여백에서 시작해 판 안으로 끌어도 모든 기법의 획이 그려져요(판 가장자리까지 꽉 채울 때 편해요).
- 세로 고정: 휴대폰은 기울여도 가로 화면으로 바뀌지 않아요(안드로이드 크롬 전체화면). 고정이 안 되는 아이폰 등은 눕히면 '세로로 세워 주세요' 안내가 뜨고, 그동안 그림은 그대로 지켜져요.
- 서랍: 도구 띠와 무늬 창 위의 「⌄」 손잡이를 누르면 각각 따로 접혀 내려가요. 아래에 남는 「도구」「무늬」 탭으로 다시 꺼내요. 오리기를 고르면 무늬 서랍은 저절로 나와요.
- 확대: 두 손가락으로 벌리거나 오므리면 옻칠판을 6배까지 키우고 옮길 수 있어요(그리던 획은 취소돼요). 컴퓨터는 마우스 휠로 해요. 오른쪽 위 「원래 크기」로 돌아와요.
- 작업대: 옻칠판 바깥은 밝은 오동나무빛이라 판과 확연히 구별돼요.
- 사진: 도구 띠나 감상 화면의 「사진」을 누르면, 그 순간의 빛 그대로 작품을 크게 찍어 액자 테두리와 붉은 낙관을 더한 PNG로 저장해요. 휴대폰에서는 공유 창이 떠서 「이미지 저장」으로 사진첩에 넣을 수 있어요.
- 감상: 도구 띠의 「감상」을 누르면 도구가 모두 서랍에 들어가고, 옻칠판이 화면 가득 커져 작품만 보여요. 이때 화면을 만지거나 휴대폰을 기울이면 빛만 움직여요. 오른쪽 아래 「도구」로 다시 꺼내요.

- 휴대폰: 도구가 아래쪽에 모여요. 따로 버튼을 누르지 않아도 휴대폰을 기울이면 빛이 따라 움직이며 자개 빛깔이 바뀌어요(아이폰은 처음 화면을 만질 때 한 번 허락을 물어요).
- 교실 TV·전자칠판(가로로 긴 화면): 도구가 왼쪽 세로 띠로 옮겨 가요.
- 카카오톡·네이버·페이스북 같은 앱 안에서 열면 크롬·사파리로 다시 열려요.

## 만든 방법

`index.html` 한 파일로 동작해요. 외부 라이브러리 없이 Canvas 2D와 WebGL로 그렸고, 글꼴은 Google Fonts의 고운바탕·고운돋움(SIL Open Font License)을 써요.
자개 무늬와 빛의 일렁임은 셰이더로 직접 계산한 것이고, 오리기 무늬는 한국 전통 문양(십장생·운학문·사군자 등)을 참고해 새로 그렸어요.
